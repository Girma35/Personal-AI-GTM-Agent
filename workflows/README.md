# n8n Workflows

Export your n8n workflows here as JSON files.

## How to Export

1. Open n8n at `http://localhost:5678`
2. Build your workflow
3. Click the **⋮** menu → **Export workflow**
4. Save the JSON file in this directory

## Naming Convention

```
workflows/
├── 01-lead-enrichment.json
├── 02-email-outreach.json
├── 03-social-monitoring.json
└── README.md
```

Prefix with phase number to match the tutorial order.
